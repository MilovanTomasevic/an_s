بنية الثقة

تربط الحدود الصريحة المنصة من دون طمس المسؤوليات.

advanexus منصة معيارية تفصل بين واجهات Tenant والواجهات الإدارية، وبين مخازن بيانات التحكم وTenant، وطوابير أعباء العمل، ومهايئات التخزين، وحدود تشغيل Python الموثوقة.

راجع بنية النشر →

01

لمستوى التحكم ومستوى بيانات Tenant وظيفتان مختلفتان.

يدير مستوى التحكم سجل Tenant وهوية المنصة وإسقاطات النظام المنقّحة. وتحتفظ قواعد بيانات Tenant بموارد المشروع وإصداراته وعمليات تشغيله ونموذج القراءة الخاص بـAssurance على مستوى Tenant.

02

تحتفظ الوحدات المرجعية بملكيتها.

تمتلك SQL Console سجل QueryExecution، ويمتلك Dataset عقد بياناته، وتمتلك Analytics تنفيذ التقارير، ويمتلك Sandbox دورات حياة الملفات والتحويل والدفاتر. ويعرض Assurance الأدلة المدعومة بدلاً من التحول إلى مالك عام للبيانات.

03

تفصل أعباء العمل المسؤوليات التشغيلية.

لكل من خدمة الويب والعاملين العامين والمتخصصين وRedis وتخزين الكائنات ومهام إسقاط Assurance وتقاريره وANPy runtime-manager احتياجات تشغيل واسترداد مستقلة.

04

مخططات البنية ليست قبولاً للنشر.

تسترشد بنية AWS المستهدفة بحدود Docker Compose الحالية. ومع ذلك، تظل الصورة المحددة والأدوار والشبكات والتخزين وقابلية الرصد والنسخ الاحتياطي وسلوك الإخفاق بحاجة إلى تحقق خاص بالبيئة.
