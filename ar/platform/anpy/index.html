Python محكوم عبر ANPy

عمل Python محكوم في بيئة تشغيل مقيدة بالمشروع.

يمنح ANPy تحليل Python بيئة معروفة وإصدار دفتر ودورة حياة للنواة وسجل CellRun، مع إبقاء عزل الإنتاج وسياسة الحزم تحت تحكم المنصة.

استكشف عقد ANPy →

01

البيئة جزء من هوية التحليل.

تُوحّد المتطلبات مقابل فهرس حزم غير متصل ومعتمد وتُخزن مع ملف Python وبيئة التشغيل وهوية SHA-256. ولا يستبدل المرشح الفاشل البيئة الجاهزة السابقة.

01يمكن لصق المتطلبات أو رفعها إلى عقد البيئة.

02يكون حل الحزم ثابتاً وغير متصل مقابل الفهرس المعتمد، ولا يُسمح بالتثبيت الاعتباطي من الإنترنت.

03تنتج Workspace وإصدار Python والمتطلبات المطبعة وملف التشغيل هوية بيئة ثابتة.

02

تخضع حالة الدفتر للإصدارات ولا تُكتب فوقها بصمت.

تستخدم مستندات nbformat 4 المرجعية حفظاً يدوياً صريحاً وETags قوية للكتابات المتزامنة. وتنشئ نقاط التحقق والاستعادة إصدارات غير قابلة للتغيير، بينما يظل رأس الدفتر المحفوظ إصداراً قابلاً للتغيير وصريحاً. ويحفظ التعارض المسودة المحلية ويتطلب اختيار مسار إعادة تحميل أو إعادة تطبيق.

03

تُتحكم دورة حياة النواة خارج المتصفح.

يتحقق مدير التشغيل الموثوق من هوية مساحة العمل والدفتر والبيئة قبل البدء أو المقاطعة أو إعادة التشغيل أو الإيقاف. ولا يمكن لمدخلات المتصفح تحديد مسارات المضيف أو الحاويات أو بيانات اعتماد التحكم.

04

إعادة التشغيل الآمنة ليست لقطة للذاكرة.

بعد إنشاء نواة جديدة، يمكن لإعادة التشغيل المحدودة إعادة بناء خلايا إعداد سابقة ناجحة وغير متغيرة فقط عندما تتطابق أدلة الإصدار وتجزئة المصدر والبيئة والتشغيل. ويفشل الدليل القديم أو غير المكتمل بشكل مغلق.

01لا يحفظ الإيقاف وإعادة التشغيل ذاكرة عملية Python.

02يمكن إعادة تشغيل الخلايا السابقة المؤهلة وغير المتغيرة بعد إنشاء جيل جديد من النواة.

03يمنع تغير المصدر أو البيئة أو عدم اكتمال دليل الخلايا السابقة إعادة التشغيل بدلاً من تخمين حالة مساحة الأسماء.

05

يبقي CellRun تنفيذ الشفرة محدوداً وقابلاً للفحص.

تحتفظ كل خلية CODE مرسلة بهوية المصدر وإصدار الدفتر وسياق البيئة والنواة وبيانات stdout وstderr الوصفية المحدودة والمدة والحالة النهائية. ولا يوفر المتصفح الحالي بث stdout حياً أو عارضاً كاملاً لـDataFrame والرسوم.

06

يحافظ ANPy على وضوح حدوده الحالية.

لا يمثل ذلك ادعاءً بتوفير MLOps كامل أو جدولة GPU أو خدمة النماذج أو تثبيت حزم اعتباطي من الإنترنت أو تركيب ضمني لـDrive أو تعاون كامل في الدفاتر المشتركة. ويعد تحديد عنصر Drive تلميحاً مؤقتاً للعنصر الحالي، لا نسب بيانات مثبتاً أو تركيباً للنواة؛ وتكون المستندات المرجعية مقيدة بالمالك بينما لا تملك مسارات التشغيل المحيطة بعد نسبة موحدة للمالك.
