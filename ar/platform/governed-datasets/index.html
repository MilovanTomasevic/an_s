مجموعات البيانات المحكومة

حوّل تعريفات البيانات إلى أصول ذات إصدارات وتسلسل نسب صريح.

يفصل Dataset بين SQL الاستكشافي وعقد بيانات قابل لإعادة الاستخدام. وتنشئ هويته الثابتة وإصداراته غير القابلة للتغيير وبياناته الدلالية أساساً محكوماً للتقارير من دون إخفاء تسلسل نسب المصدر.

شاهد Analytics المحكومة →

01

Dataset عقد، وليست نتيجة استعلام أُعيدت تسميتها.

تربط Dataset تسلسل نسب المصدر والاستعلام وSQL المطبعة والبيانات الوصفية للأعمدة والدلالات وحالة دورة الحياة وDatasetVersions غير القابلة للتغيير. ويظل SavedQuery عبارة SQL قابلة للتحرير، بينما يصف Report القصد التحليلي.

01يمكن أن تنشأ Dataset من تنفيذ SQL Console أو SavedQuery أو جدول مادي أو تحويل محكوم.

02يسجل DatasetColumn بيانات المخطط والملف التعريفي المعروفة للإصدار الدقيق.

03تعمل ترقية SQL Console على مواءمة Dataset المرجعية مع الإسقاط الدلالي لـAnalytics من دون دمج حدود ملكيتهما.

02

يعني الإصدار الحالة الدقيقة للعقد.

يؤدي تغيير SQL أو عمليات الربط أو المصدر أو المخطط أو الأعمدة أو بيانات الأعمدة الوصفية المملوكة لـDataset إلى إنشاء DatasetVersion جديد. وتظل مقاييس Analytics وأمن مستوى الصفوف وصلاحيات التقارير عقوداً منفصلة. وتبقى ReportVersions القائمة مثبتة حتى يتحقق المستخدم من DatasetVersion الجديد ويحفظ ReportVersion جديداً.

Report v4 → Dataset v2 · Report v5 → Dataset v2 · Report v6 → Dataset v3

03

لا يجمّد الإصدار الافتراضي الصفوف تلقائياً.

عندما يخزن DatasetVersion عقد SQL حياً، يمكن لعمليات التشغيل اللاحقة قراءة صفوف مصدر أحدث مع استخدام التعريف نفسه. وتتطلب إعادة بناء النتيجة التاريخية بدقة تجزئة التشغيل والأصل المحتفظ به أو لقطة مادية صريحة.

04

تعرض المقارنة التغيير المسجل، لا أثراً مختلقاً.

يمكن للمستخدمين مقارنة SQL المطبعة والأعمدة والأنواع وبيانات النسب الوصفية المعروفة. ولا تدّعي المنصة تحليلاً شاملاً للأثر التجاري اللاحق للعلاقات التي لم تُسجل قط.

01هوية دقيقة للإصدارين الأيسر والأيمن وعقد SQL بتجزئة SHA-256

02مقارنة SQL مدركة للأسطر مع الإضافات والحذف

03تغييرات الأعمدة والأنواع وقابلية القيمة الفارغة والبيانات الوصفية المعروفة

04حالات صريحة لغير المتغير والمتغير والمضاف والمحذوف وغير المتاح

05

تحتفظ Dataset وAnalytics بمسؤوليات منفصلة.

تملك Dataset أصل البيانات الثابت وإصداراته. وتملك Analytics المقاييس وأمن مستوى الصفوف وصلاحيات الموارد وسياق الاستعلام وتنفيذ التقارير. ويُبقي هذا الفصل حدود الحوكمة قابلة للمراجعة.

06

التطور قرار قبول صريح.

لا ينقل DatasetVersion الجديد التقارير القائمة بصمت. يقارن المستخدم العقد ويتحقق من الأبعاد والمقاييس ويعاين الاستعلام المُنشأ، ثم يحفظ ReportVersion جديداً مرتبطاً بـDatasetVersion المقبول. وتحتفظ ReportVersions وعمليات التشغيل الأقدم بعمليات الربط الأصلية.

  1. 01

    قارن Dataset v2 بـv3.

  2. 02

    أكّد SQL والأعمدة والأنواع المتغيرة.

  3. 03

    افتح مسودة التقرير مقابل Dataset v3.

  4. 04

    تحقق من البيانات الوصفية واجمع SQL للقراءة فقط.

  5. 05

    عاين ضمن سياق الصلاحيات وأمن مستوى الصفوف الحالي.

  6. 06

    احفظ Report v6 ← Dataset v3 بعد القبول فقط.
