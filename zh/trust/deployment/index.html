部署模型

生产就绪属于特定环境中的特定构建。

运行时图和存储库测试描述边界。生产签署要求针对不可变制品记录迁移、授权、恢复、存储、连接器、浏览器和运营验收。

讨论部署范围 →

01

当前运行环境让工作负载边界具体可见。

在当前运行时模型中，租户交付、管理控制、持久数据、异步工作负载、保留制品、受控 Python 和 Assurance 恢复路径保持分离。

02

AWS 托管服务属于目标架构。

数据库、缓存、对象存储、秘密、密钥、日志和工作负载服务可以映射到 AWS 托管能力。本存储库不声称交付通用的生产 ECS 或 CDK 栈。

03

验收覆盖失败，而不仅是启动。

迁移账本、负向授权路径、消息代理故障、重新投递、过期任务恢复、存储篡改、备份与恢复、连接器认证和回滚演练均属于签署范围。

04

公共状态无法认证客户环境。

能力标签描述当前产品范围。客户与部署责任人必须记录所选架构的基础设施、安全、法律和运营验收。
