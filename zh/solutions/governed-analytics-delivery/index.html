受治理的分析交付

明确哪个数据契约、权限、筛选器和报告版本产生了结果。

交付图表或仪表板时保留日后解释所需的准确版本绑定与运行上下文，同时明确区分运行时筛选器和服务器拥有的 RLS。

探索受控 Analytics →

01

将分析意图绑定到准确的数据契约。

不可变的 ReportVersion 捕获分析配置，并指向其接受的 DatasetVersion。更新图表或切换到新的 Dataset 契约都会创建新的报告版本。

02

让执行状态保持可见。

AnalyticsRun 记录权限与 RLS 范围、筛选器、绑定、状态、诊断和有限制品。多绑定的部分成功会在每个绑定层面保持可见。

03

受治理的执行补充现有 BI。

advanexus 不声称取代 BI 平台中的每一个展示层或语义层。它在准确版本和执行上下文至关重要的场景中，提供受控的 Report 与证据路径。

受控分析 固定数据契约。治理执行。解释结果。

受控 Analytics 将报告绑定到准确 DatasetVersion，在服务器上验证 Query Context，并保留受支持结果背后的权限、RLS、筛选器、绑定和制品上下文。

→ 受治理的数据集 将数据定义转化为具有明确血缘的版本化资产。

Dataset 将探索性 SQL 与可复用数据契约分离。其稳定身份、不可变版本和语义元数据为报告建立受控基础，同时不隐藏来源血缘。

→ advanexus Assurance 通过结果背后的可用证据调查受支持的结果。

Assurance 是感知权限、针对读取优化的层，用于探索受支持的运营证据。它不会取代权威来源，也不会编造从未记录的历史。
