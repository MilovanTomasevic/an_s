受控分析

固定数据契约。治理执行。解释结果。

受控 Analytics 将报告绑定到准确 DatasetVersion，在服务器上验证 Query Context，并保留受支持结果背后的权限、RLS、筛选器、绑定和制品上下文。

探索报告生命周期 →

01

ReportVersion 捕获分析意图。

维度、指标、聚合、图表、持久筛选器、交互和 DatasetVersion 绑定属于不可变 ReportVersion。运行时筛选器会创建新的运行上下文，而不是静默更改已保存定义。

02

服务器拥有编译与 RLS。

浏览器 Query Context 引用获授权的列与指标。后端验证并编译只读 SQL。运行时筛选器不能冒充受保护的 RLS 来源元数据。

03

可视化共享一套契约。

柱状图、横向柱状图、折线图、面积图、可选大小的散点图、饼图、环形图、表格、KPI 和多系列图表使用同一套版本化且与渲染器无关的契约。具有确定性“其他”项的 Top N、时间粒度、比较、钻取、参考线和无障碍回退均属于同一规范。

01类型化运行时筛选器从所选列契约推导有效运算符与占位符。

02Inspect Data 支持有限分页、排序和列投影，无需重新定义已保存报告。

03有限 CSV、JSON 和图像导出会保留截断与血缘元数据。

04自动刷新会创建新的运行上下文，不会修改不可变 ReportVersion。

04

运行会保留部分结果。

AnalyticsRun 记录版本绑定、状态、筛选器、权限与 RLS 范围、行数、诊断和制品。多绑定按顺序执行已保存绑定并显示每个绑定的部分成功；叠加、联合与合并行为仍是明确报告配置，而不是推断出的连接。

01持久执行采用幂等性、有限重试、超时、取消、租约和过期运行回收。

02运行事件支持实时回放，并在流式传输不可用时回退到轮询。

03失败绑定保留自身安全诊断；成功绑定不会把整个运行错误地标记为完全成功。

05

仪表板不会抹去组件失败。

仪表板与组件运行保留与底层报告及 AnalyticsRun 身份的连接。一个组件失败不会隐藏成功组件，也不会被包装成虚假的完全成功。

06

制品与缓存保留治理身份。

结果样本、概要、图表载荷、有限完整结果和诊断保留 SHA-256、大小、保留与血缘元数据。本地或 S3 读取受到限制并执行完整性检查；公共定位符保持不透明。缓存身份包含报告与 Dataset 版本、权限/RLS 范围、图表/配置契约、执行策略、限制和哈希化 SQL 参数。

07

当前编译范围保持明确。

当前受治理且感知 Dataset 的编译器面向 PostgreSQL。其他来源系列需要已验收的物化或方言适配器；仅有连接器并不能提供该路径。

受治理的数据集 将数据定义转化为具有明确血缘的版本化资产。

Dataset 将探索性 SQL 与可复用数据契约分离。其稳定身份、不可变版本和语义元数据为报告建立受控基础，同时不隐藏来源血缘。

→ advanexus Assurance 通过结果背后的可用证据调查受支持的结果。

Assurance 是感知权限、针对读取优化的层，用于探索受支持的运营证据。它不会取代权威来源，也不会编造从未记录的历史。

→ 受治理的分析交付 明确哪个数据契约、权限、筛选器和报告版本产生了结果。

交付图表或仪表板时保留日后解释所需的准确版本绑定与运行上下文，同时明确区分运行时筛选器和服务器拥有的 RLS。
