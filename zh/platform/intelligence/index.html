advanexus Intelligence

在平台权限、策略与证据边界内提供 AI 辅助。

用户用自然语言描述目标。Intelligence 只组装允许的上下文，选择已注册技能，并让确定性平台服务继续掌握验证与执行权。

查看负责任的 AI 控制 →

01

目标通过所有者私有状态延续。

Intelligence 工作区与全局面板共享所有者私有的会话、目标、消息和 Turn 生命周期。范围可以是全局、Project 或准确对象。后端契约提供重命名、固定、导出、反馈和记忆 API，但部分控制尚未在所有浏览器界面公开。

02

有依据的上下文从服务器拥有的范围开始。

Intelligence 在服务器上重建 Actor、Tenant、Project、权限与 RLS 上下文。全局面板接收已注册页面、所选对象和允许列表提示；不会抓取任意 DOM、编辑器内容或结果网格。

01Actor、Tenant、当前 Project 与有效权限

02页面工作流键与准确所选对象引用

03有限、已脱敏的 Source、SQL 与权威元数据

04经依赖与策略筛选后可用的技能与工具

03

技能与配置选择属于策略，而非人格化表演。

十七项版本化技能将意图路由到有限提示与能力集合。Luna、Terra 和 Sol 是服务器拥有、基于同一固定模型的策略配置，而不是用户可选模型或独立授权域。

04

提议不等于操作。

模型可以解释、起草并请求已注册工具。平台会再次验证工具身份、参数、范围与策略。预览或写入操作需要遵循分配给该准确能力的确认或审批契约。

目标 → 有依据的上下文 → 提议 → 验证 → 确认或审批 → Action → 证据

05

权威服务执行实际工作。

SQL、Dataset、Analytics、Assurance、Service Desk 和其他已注册适配器调用现有应用服务，而不是创建平行 AI 执行平面。仅响应的 Turn 可以在给出解释后完成；改变状态的结果只有通过连接到权威模块的已完成 Action 或工具结果才能得到证明。

01Source 与 SQL Console——元数据、安全 SQL 验证、有限且经确认的预览及 SavedQuery 创建

02Dataset、Data Quality 与 Analytics——准确资产查找、分析指导和严格注册的有限受控写入

03ANPy——在服务器端验证模型代码 AST，绝不由 AI 执行 Python 单元

04Assurance 与 Service Desk——限定范围查找，以及准确契约允许时的已注册 Case、证据包或工单操作

06

SQL 辅助有依据且感知方言。

当用户请求分析 Dataset 或查询时，Intelligence 使用当前选定且获授权的 Source、架构与元数据，说明分析粒度、维度、指标和图表选择，并在呈现或预览前验证草稿。它不会静默切换数据库，也不会把 SQL 文本视为执行证明。

07

持久执行将实时进度与权威状态分离。

启用异步模式后，所有配置都会在执行前持久化已排队 Turn。持久事件保持权威，实时回放与轮询提供进度。停止、重新生成、过期工作恢复和延迟结果保护遵循同一有限生命周期。

08

容量与使用始终明确。

准入控制在使用提供商前应用有限并发与滚动速率租约。版本化的全局、租户或用户 LIMITED 与 UNLIMITED 策略可以治理令牌容量；提供商使用和版本化成本归属仍是运营记录，而不是硬货币预算或跨区域共识机制。

09

边界是有意设计的。

Intelligence 不提供通用屏幕抓取、网络搜索、浏览器自动化、自主工作流图或任意工具访问，也不会继承当前用户不具备的数据或权限。

01在不存在权威可执行适配器时，Drive、Sandbox 和流程形式化仅提供响应。

02Pipeline 执行、重试和取消以及 Data Quality 规则执行不属于当前 Intelligence 操作。

03Analytics 写入仅限基于准确 DatasetVersion 且经确认的 TABLE 报告草稿；它不是通用图表或仪表板创作。

04自动文档 RAG、每租户提供商账户、硬货币预算和完整保留/法律保留界面不属于当前能力。

10

有用的回答具体且诚实。

高质量响应使用所选 Source 或对象，区分事实与假设，在需要时提供经验证的 SQL，解释分析粒度与价值，并在上下文不足时安全停止。

负责任的 AI 模型不是安全边界。

advanexus Intelligence 将自然语言推理与确定性授权和执行分离。有效响应绝不会自行授予访问权，也不会把生成文本直接转化为未经审阅的平台操作。

→ advanexus Assurance 通过结果背后的可用证据调查受支持的结果。

→ 面向 BI 与 AI 的可信输入 为分析和 AI 提供已知、经验证且受治理的输入契约。

将选定来源或文件结果提升为稳定的 Dataset 身份，记录质量结果，并保留报告或已注册 Intelligence 工作流获准使用的准确版本。
