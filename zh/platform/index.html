平台总览

一套系统，将业务结果与实际发生的事项连接起来。

advanexus 将受支持的数据操作、受治理资产、分析、Python 工作、已登记 AI 辅助操作与 Assurance 纳入一个范围明确的运行模型。每个模块继续保留规范所有权；企业则获得一条从意图与授权到结果与证据的连续路径。

跟随控制路径 →

01

Tenant 与 Project 让范围成为执行决策。

Tenant 是组织与数据隔离边界。Project 是其中的成员关系与执行范围，而非浏览器显示筛选器。Project 选择控制有效角色、数据库搜索路径和项目范围模块可见的资源。

受治理的配置

创建 Project 时，会对齐租户数据库、创建由标记拥有的架构、应用运行时授权，并在发布映射前注册 System Sandbox Source。

当前上下文

由服务器拥有的会话状态绑定 Actor、Tenant 和当前 Project；受保护请求会重新验证该上下文，而不是信任标头或页面状态。

明确例外

Assurance 是租户级读取模型，Service Desk 是带可选项目上下文的租户级队列，Intelligence 可使用全局、项目或准确对象范围。

02

共享对象让生命周期易于理解。

Actor、Source、FileVersion、TableVersion、DatasetVersion、ReportVersion、Environment、Run、Artifact、Evidence、Finding、Case 和 Ticket 分别保留不同的权威所有者。它们之间的明确关系比一条通用活动流更有价值。

01Version 标识准确的已记录契约状态；除非契约明确说明，否则并不意味着实时数据行快照。

02Run 标识一次执行尝试及其终态或部分结果。

03Artifact 标识已保留的有限输出、概要、诊断或导出材料。

04Evidence 记录权威来源能够支持的内容，并让缺失上下文保持可见。

03

连接与发现。

注册 Project 范围内的 Source，解析驱动程序能力，检查元数据，并在把结果提升为持久资产前进行有限只读探索。

01Source 与连接器能力契约

02持久 SQL Console 工作区、SavedQuery 与 QueryExecution

03不可变 Sandbox FileVersion 与感知内容的预检

04

构建与验证。

保留不可变文件版本，检查内容，发布托管表版本，应用 Data Quality 断言，并为已实现 Pipeline 流程保留执行结果。

01验证后的原子稳定别名发布

02面向来源的 QualityRun 与有限发现

03持久化查询、传输、删除、质量与 Master 运行结果

05

治理与分析。

为数据定义赋予稳定 Dataset 身份，将 ReportVersion 固定到准确 DatasetVersion，并在已知权限、RLS 与筛选器上下文中执行 Analytics。

01Dataset 契约与不可变版本比较

02具有逐绑定诊断的多绑定 AnalyticsRun

03保留各组件运行结果的仪表板

06

通过受控 Python 扩展。

ANPy 连接笔记本修订、环境身份、内核生命周期和有限 CellRun，同时不会把进程内存描述为持久证据。

07

理解、调查与证明。

Intelligence 帮助用户推理并准备已注册操作；Assurance 将受支持记录连接到限定范围的调查、发现、案例、完整性状态和证据包。

08

身份、入门与设置始终是运营模型的一部分。

受控入门流程配置 Tenant 与 Project 访问；设置功能管理账户、团队角色和 Tenant SAML 策略。已认证请求必须匹配有效会话注册表记录、当前 Tenant／用户状态和服务器管理的权威来源。

企业入口

默认受控路径是由平台管理员配置租户、强制更改临时密码并明确创建 Project，而不是假定提供公开自助注册。

团队访问

当前入门流程会立即创建或复用用户并分配角色；它不是邀请邮件或待处理令牌生命周期。

SAML 与 MFA 证据

已提供 SAML 元数据/登录/ACS、JIT 身份关联、域策略和由 IdP 断言的 MFA 证据；应用 TOTP/WebAuthn 和完整增强认证界面尚未提供。

会话安全

注册表状态被撤销、过期或不匹配时会安全关闭；密码更改、重置和账户删除都会撤销有效会话。

09

Service Desk 连接运营沟通，但不会仅凭声明把沟通变成证据。

租户用户可以创建并跟踪有限的支持、账单、安全、缺陷、功能和事件工单。平台管理员可以回复、添加内部备注、分派和更改状态；受支持工单事件可投影到 Assurance。

01租户队列覆盖整个租户；项目身份是可选上下文，而不是列表授权谓词。

02内部备注对租户模板保持隐藏，公开回复则保留为租户会话的一部分。

03附件、SLA 自动化、邮件/Webhook、不可变 TicketVersion 和完整 ITSM/CMDB 行为不属于当前能力。

10

引导式导览解释真实产品，而非播放脱节的视频。

共享导览基础设施可以通过合成示例、播放/暂停/下一步控制和类似页面的模态界面演示 SQL Console、Dataset 详情与 Analytics。导览讲解工作流和边界，但不会执行租户操作或替代文档。

11

能力状态是产品契约的一部分。

可用、面向生产、取决于环境和规划中是不同状态。公共功能声明永远不能替代针对准确修订和部署的在线验收。

相关视角

数据操作 在明确的范围与运行上下文中连接、检查、转换和执行。

从异构 Source 和受控文件进入托管表、质量检查和持久化执行历史，同时不把所有连接器强行简化成同一种查询或写入模型。

→ 受治理的数据集 将数据定义转化为具有明确血缘的版本化资产。

Dataset 将探索性 SQL 与可复用数据契约分离。其稳定身份、不可变版本和语义元数据为报告建立受控基础，同时不隐藏来源血缘。

→ advanexus Assurance 通过结果背后的可用证据调查受支持的结果。

Assurance 是感知权限、针对读取优化的层，用于探索受支持的运营证据。它不会取代权威来源，也不会编造从未记录的历史。

→ advanexus Intelligence 在平台权限、策略与证据边界内提供 AI 辅助。

用户用自然语言描述目标。Intelligence 只组装允许的上下文，选择已注册技能，并让确定性平台服务继续掌握验证与执行权。
