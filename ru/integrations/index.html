Интеграции

Подключайте разнородные системы через явные контракты возможностей.

Название коннектора — лишь отправная точка. advanexus определяет, какие операции обнаружения, чтения, передачи, записи, контроля качества и аналитики конкретный драйвер и вариант развёртывания способны безопасно поддерживать.

Обсудить ландшафт источников →

01

Семнадцать контрактов коннекторов в восьми семействах возможностей — без ложной эквивалентности.

Каталог охватывает PostgreSQL, совместимость с MySQL и MariaDB, Microsoft SQL Server, Oracle, IBM Db2, SQLite, SAP HANA, Snowflake, Databricks SQL, DynamoDB, MongoDB, Redis, Cassandra, Neo4j, Elasticsearch, OpenSearch и Salesforce.

02

Возможности определяются раньше, чем действия в интерфейсе.

Реляционные, документные системы, системы «ключ — значение», системы с широкими столбцами, поисковые, графовые и SaaS-системы не используют единую естественную модель запросов. Интерфейс должен предлагать только те операции с метаданными, предварительным просмотром, запросами, передачей, удалением или качеством, которые предоставляет текущий контракт Source.

03

Подключение — это решение, зависящее от среды.

Клиенты поставщиков, сетевые маршруты, TLS, учётные данные, привилегии, ограничения API и целевые политики проверяются в целевой среде развёртывания. Наличие коннектора в публичном каталоге не означает сертификацию всех версий продукта поставщика.

04

Прямой путь контролируемой Analytics намеренно уже.

Текущий компилятор Analytics с учётом Dataset ориентирован на PostgreSQL. Другие коннекторы могут участвовать через принятый путь материализации или адаптер диалекта; само присутствие в каталоге не даёт им прямой поддержки компилятора.

05

Контракты возможностей коннекторов

Возможности зависят от коннектора, драйвера и принятого варианта развёртывания.

Реляционные системы

Зависит от среды

PostgreSQL

Управляемый реляционный источник для обнаружения данных, контролируемого SQL и поддерживаемых операций с данными.

Посмотреть контракт возможности
Типовой управляемый путь
От Source к SQL Console, Dataset, Data Quality, Pipeline и управляемой Analytics.
Модель возможностей
Возможности подключения, работы с метаданными, запросов, переноса, записи и контроля качества определяются контрактом развёрнутого драйвера.
Важное ограничение
Текущий управляемый Analytics-компилятор с поддержкой Dataset предназначен для PostgreSQL; каждая возможность среды выполнения по-прежнему требует сертификации.

Реляционные системы

Посмотреть контракт возможности
Типовой управляемый путь
Обнаружение Source, ограниченные операции чтения и разрешённые возможностями процессы переноса или контроля качества.
Модель возможностей
Каждая операция определяется драйвером семейства MySQL и целевой средой.
Важное ограничение
Совместимость не означает одинакового поведения всех версий и конфигураций MySQL или MariaDB.
