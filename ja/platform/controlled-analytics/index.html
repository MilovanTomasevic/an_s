制御された Analytics

データ契約を固定する。実行をガバナンスする。結果を説明する。

制御された Analytics は、Report を正確な DatasetVersion に結び付け、Query Context をサーバー上で検証し、対応済み結果の背後にある権限、RLS、フィルター、バインディング、アーティファクトのコンテキストを保持します。

Report のライフサイクルを見る →

01

ReportVersion は分析上の意図を記録します。

ディメンション、指標、集計、チャート、永続フィルター、操作、DatasetVersion との結び付きは、すべて不変の ReportVersion に属します。実行時フィルターは保存済みの定義を暗黙に書き換えず、新しい実行コンテキストを作成します。

02

コンパイルと RLS はサーバーが管理します。

ブラウザーの Query Context は、許可された列とメトリクスを参照します。バックエンドがそれを検証し、読み取り専用 SQL をコンパイルします。実行時フィルターが、保護された RLS オリジンメタデータになりすますことはできません。

03

可視化は 1 つの共通契約を使用します。

棒、横棒、折れ線、面、任意のサイズを持つ散布図、円、ドーナツ、テーブル、KPI、複数系列チャートは、1 つのバージョン管理されたレンダラー非依存契約を使用します。決定論的な Other を伴う上位 N 件、時間粒度、比較、ドリル、基準線、アクセシブルな代替表示も同じ仕様に含まれます。

01型付き実行時フィルターは、選択した列契約から有効な演算子とプレースホルダーを導出します。

02Inspect Data は、保存済み Report を再定義せず、上限付きページング、並べ替え、列投影に対応します。

03上限付き CSV、JSON、画像エクスポートは、切り詰めとリネージュのメタデータを保持します。

04自動更新は新しい実行コンテキストを作成し、不変の ReportVersion を変更しません。

04

実行は部分的な成果を保持します。

AnalyticsRun は、バージョンバインディング、状態、フィルター、権限と RLS のスコープ、行数、診断、アーティファクトを記録します。複数バインディングは保存済みバインディングを順次実行し、バインディングごとの部分成功を示します。重ね合わせ、和集合、統合の動作は、推測された結合ではなく、明示的な Report 構成です。

01永続的な実行では、冪等性、上限付き再試行、タイムアウト、キャンセル、リース、古い実行の回収を使用します。

02実行イベントはライブ再実行に対応し、ストリーミングが利用できない場合はポーリングへ代替表示します。

03失敗したバインディングは固有の安全な診断を保持します。成功したバインディングが、実行全体を誤った完全成功へ変換することはありません。

05

ダッシュボードはウィジェットの失敗を消去しません。

ダッシュボードとウィジェットの実行は、基礎となる Report と AnalyticsRun のアイデンティティへの接続を保持します。1 つのウィジェットが失敗しても、成功したウィジェットを隠したり、誤った完全成功として扱ったりする必要はありません。

06

アーティファクトとキャッシュはガバナンス上のアイデンティティを保持します。

結果サンプル、プロファイル、チャートペイロード、上限付き全結果、診断は、SHA-256、サイズ、保持、リネージュのメタデータを保持します。ローカルのまたは S3 の読み取りには上限と完全性検証があり、公開ロケーターは不透明なままです。キャッシュ識別情報には、Report と Dataset のバージョン、権限／RLS スコープ、チャート/設定契約、実行ポリシー、上限、ハッシュ化された SQL パラメーターが含まれます。

07

現在のコンパイル範囲は明示されたままです。

現在、ガバナンスされた Dataset 対応コンパイラーは PostgreSQL を対象とします。他の Source ファミリーには、承認済みのマテリアライゼーションまたは方言アダプターが必要であり、コネクターが存在するだけではその経路は提供されません。

関連する視点

ガバナンスされた Dataset データ定義を、明示的なリネージュを持つバージョン管理資産へ変換します。

Dataset は探索用の SQL と再利用可能なデータ契約を分離します。安定した識別情報、不変のバージョン、セマンティックなメタデータにより、ソースリネージュを隠さずに Report の制御された基盤を作ります。

→ advanexus Assurance 対応済みの成果を、その背後にある利用可能な証拠から調査します。

Assurance は、対応する運用証拠を探索するための、権限認識型かつ読み取り最適化されたレイヤーです。正規ソースを置き換えることも、記録されていない履歴を作り出すこともありません。

→ ガバナンスされた Analytics 提供 どのデータ契約、権限、フィルター、Report バージョンが結果を生成したか把握します。

実行時フィルターとサーバー管理の RLS を区別したまま、後から説明するために必要な対象バージョンバインディング／実行コンテキストとともにチャート／ダッシュボードを提供します。
